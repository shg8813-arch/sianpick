# 시안픽 (SianPick) — 시각디자인 시안 전달 & 고객 피드백 플랫폼 MVP

> **"시안을 보고, 고르고, 수정하고, 확정하는 가장 쉬운 방법"**  
> 디자인 스튜디오와 클라이언트 간의 비주얼 피드백, 버전 관리, 수정 횟수 보호, 토너먼트형 **시안 월드컵**을 제공하는 웹 애플리케이션입니다.

---

## 개편된 비즈니스 워크플로우

1. **클라이언트(업체) 관리**
   - 대시보드에서 클라이언트 **업체(Company)를 먼저 등록**합니다. (업체명, 담당자, 연락처, 메모 등)
   - 등록된 업체를 선택하여 해당 업체에 소속된 **디자인 프로젝트를 등록**합니다.

2. **디자인 항목(Design Items) 직접 작성 생성**
   - 프로젝트 상세 관리에서 프로젝트에서 납품할 구체적인 디자인 품목을 생성합니다.
   - **예시: 로고, 컵홀더, 메뉴판, 간판, 리플렛 등**
   - **자동화 프리셋 버튼 없이 디자이너가 원하는 항목명을 직접 텍스트로 입력하여 유연하게 생성**합니다.

3. **각 디자인 항목별 시안 등록 & 선택**
   - 각 디자인 항목마다 여러 개의 시안을 독립적으로 등록/관리합니다.
   - 고객 공유 페이지(`share/[shareToken]`):
     - 디자인 항목별 탭을 통해 깔끔하게 분리된 시안 열람.
     - 각 항목별로 **"이 시안 선택하기"** 지원.

4. **고객 선택시안 전용 페이지 (`/summary`)**
   - 고객이 각 디자인 항목별로 고른 대표 시안들을 한곳에 깔끔하게 카드 형태로 정리하여 보여줍니다.
   - 미선택 항목이 있을 경우 즉시 시안 선택으로 유도.
   - **최종 확정 승인**을 한 곳에서 수행 가능.

5. **DEMO MODE (즉시 실행 & 브라우저 저장)**
   - Supabase 계정이나 환경변수 설정이 없어도 로컬스토리지 기반으로 즉시 작동합니다.
   - 초기 샘플 업체(어반 포레스트), 프로젝트, 3개 디자인 항목(로고, 친환경 패키지, 쇼룸 메뉴판)과 각 시안들이 완벽히 세팅되어 있습니다.

## 데모 체험 링크 안내

- **메인 랜딩 페이지**: `http://localhost:3000/`
- **디자이너 관리자 대시보드 (업체 관리 & 프로젝트 목록)**: `http://localhost:3000/dashboard`
- **어반 포레스트 프로젝트 상세 (디자인 항목 & 시안 관리)**: `http://localhost:3000/dashboard/projects/demo-project-urbanforest`
- **고객 전용 공유 화면**: `http://localhost:3000/share/urbanforest-sample-2026`
- **고객 선택시안 모아보기**: `http://localhost:3000/share/urbanforest-sample-2026/summary`
- **고객 견적서 확인**: `http://localhost:3000/share/urbanforest-sample-2026/estimate`

## 빠른 시작 방법 (Quick Start)

```bash
# 개발 서버 실행
npm run dev

# 또는 빌드 후 프로덕션 서버 실행
npm run build
npm run start
```
브라우저에서 `http://localhost:3000`으로 접속합니다.
